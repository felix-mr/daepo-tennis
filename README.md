# 대포클럽 대진표

GitHub Pages에서 제공할 정적 대진표. 화면 주소는 공개 URL이며, 현재 HTML에는 검색엔진에 노출하지 말라는 `noindex` 요청이 들어 있다. `noindex`는 로그인이나 접근 제한이 아니다.

현재 `2026-10-03` 대진표는 정가영 불참, 남자 게스트 송효종 참석 기준이다. 이재원은 08:00부터 4경기 연속 후 10:00 종료하며, 연속 경기·휴식 제한에서 예외다. 김영진은 08:30 시작, 조아라는 10:30 종료다. 전원 4경기, 페어 중복 없음, 층 이동 개인 최대 2회·전체 12회로 검증했다.

## 날짜별 대진표

`main`은 GitHub Pages 게시 브랜치다. 날짜별 주소는 브랜치가 아니라 폴더로 구분한다.

- 날짜별 목록: `https://felix-mr.github.io/daepo-tennis/`
- 2026년 10월 3일 대진표: `https://felix-mr.github.io/daepo-tennis/2026-10-03/`

다음 주 대진표를 만들 때는 기존 날짜 폴더를 남겨 둔다. 생성기는 새 날짜 폴더와 날짜별 목록을 만든다.

## 다음 대진표 만들기

1. `src/build.py`의 `SCHEDULE_DATE`를 해당 토요일로 바꾸고 참가자와 `ROUNDS`를 수정한다.
2. 이번 주 조건에 맞게 검증 규칙도 갱신한다.
3. `python3 src/build.py`를 실행한다. 날짜 폴더의 `index.html`과 루트의 날짜별 목록 `index.html`이 생성된다.
4. 생성된 파일과 `src/build.py`를 함께 커밋한다. `main`에 반영되면 GitHub Pages가 게시한다.

`src/build.py`는 경기 수, 연속 휴식, 연속 4경기, 필수 페어, 맞대결, 층 이동 횟수를 검증한다. 현재 대진표 기준 검증이므로 다음 주 조건이 바뀌면 해당 검증도 함께 조정한다.

날짜별 `index.html`은 고죠 이미지를 포함한 단일 파일이다. `src/gojo.webp`는 원본 이미지로 보관한다.

## 내 대진 찾기

페이지 맨 위에서 이름을 입력한다. 정확한 이름을 입력하거나 검색 결과에서 이름을 누르면 그 선수의 6타임 경기·휴식, 코트, 페어와 상대만 보인다. `전체 대진표 보기`를 누르면 전체 화면으로 돌아간다. 선택한 선수는 주소의 `?player=이름`에도 반영돼 해당 선수 화면을 바로 열 수 있다. 검색은 페이지 안에서 처리하며 별도 서버나 데이터 저장은 없다.

## 배포

저장소 Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)`.

## 이후 기록

지난 대진표는 날짜 폴더와 Git 커밋 이력으로 보존된다. 참석·대진·결과를 데이터로 검색하거나 사이트에서 입력하려면 별도 데이터 파일과 화면 기능을 추가해야 한다.
